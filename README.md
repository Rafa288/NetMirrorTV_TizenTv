# 📺 NetMirrorTV_Tizen

Aplicación multimedia experimental para televisores inteligentes Samsung con **Tizen OS**, diseñada para explorar la reproducción de vídeo y adaptar una interfaz de contenido multimedia a la pantalla del televisor.

<p align="center">
  <strong>Samsung Smart TV · Tizen OS · AVPlay</strong>
</p>

## ✨ Características

* 📺 Interfaz adaptada a televisores Samsung Smart TV.
* 🎬 Navegación por contenido bajo demanda (VOD).
* 📡 Interfaz para canales de televisión en vivo.
* ▶️ Integración con la API nativa AVPlay de Tizen.
* 🌐 Reproductor HTML5 alternativo para pruebas en navegadores compatibles.
* 🔌 Conexión con una API para obtener catálogos y detalles del contenido.
* 🧪 Herramientas de desarrollo y pruebas de compatibilidad.

## 🛠️ Tecnologías

* HTML5
* CSS3
* JavaScript
* Samsung Tizen Web APIs
* AVPlay
* Tizen Studio

## 📋 Requisitos

* Un televisor Samsung compatible con Tizen OS.
* Tizen Studio y sus herramientas de desarrollo.
* Certificado de desarrollo válido para instalar la aplicación en el televisor.
* Fuentes multimedia y servicios API accesibles y autorizados.

## 🚀 Instalación y desarrollo

1. Clona este repositorio:

   ```bash
   git clone https://github.com/TU-USUARIO/NetMirrorTV_Tizen.git
   ```

2. Abre **Tizen Studio**.

3. Importa el proyecto como una aplicación web de Tizen.

4. Configura el certificado de desarrollo y el dispositivo de destino.

5. Compila la aplicación y ejecútala en un emulador compatible o en un televisor Samsung habilitado para depuración.

> Los pasos concretos pueden variar según la versión de Tizen Studio y del televisor.

## 🧪 Estado del proyecto

**Estado: en desarrollo experimental.**

Actualmente, el proyecto se centra en la interfaz de usuario, la integración de AVPlay y las pruebas de comunicación con la API. La compatibilidad de reproducción debe verificarse en cada dispositivo y con cada formato multimedia.

Algunas funciones pueden estar incompletas o no funcionar en todos los televisores.
